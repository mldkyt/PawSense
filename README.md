# PawSense

Cat-Like Behaviour Detected Window, for Windows XP and newer.

## Building

1. Clone the repository
2. Open the project in Visual Studio 2022. Preferably have the .NET Framework 3.5 tools, and have the respective feature enabled.
3. Build the project in release mode

## Development

1. You can make an account on this git forge, so register one using GitHub or Discord.
2. Fork the repository
3. Make your changes
4. Open a pull request, and I'll review the code and pull it in.
